CapacityConnect — SIH26075 Demo

This is a standalone beginner-friendly prototype.
Open index.html in a browser to run it locally.

Main demo flow:
Dashboard -> My Courses -> Learning -> Assessment -> Learning Gap

For GitHub Pages:
1. Create a public repository named capacity-connect.
2. Upload index.html to the root of the repository.
3. Settings -> Pages -> Deploy from a branch.
4. Branch: main; Folder: /(root); Save.
5. The live URL will be:
   https://lalith1316.github.io/capacityconnect-sih26075

Note: This is a prototype. The learning-gap logic is illustrative and not an official government scoring system.
